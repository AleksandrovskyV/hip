c4d_svg_parse.py - код sop python node в houdini 19.5 для парсинга svg.
Файл "wgs84_main_f-c4d.svg" это тестовый svg файл, корректно отображаемый 
в adobe-illustrator и в браузерах: chrome\edge.

При попытке пропарсить файл через ноду "c4d_svg_parse", paths c id:
"ocean_mask"- получается не закрытым
"eurasia"   - не вычитает дырку-море

Все остальные слои отображаются нормально, 
но являются обычными union-типом области.

Нода, написана из определенных требований: 
- Работает строго из набора линейных сплайнов (без cubic\bezier решений) 

И не ищу решений вставлять огромный парсер svg, на все случаи жизни
